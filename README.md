# 智能快递驿站仓储追踪管理系统

> RFID识别 · 环境监测 · 多传感采集 · 通信仿真 · 远程控制 · 安防联动 · 边缘计算 · 全链路溯源

## 功能概览

### 上行采集（7类传感器）
- 📡 RFID 读写器 (UHF-R2000) — 16位编码解析、网点映射、类型识别、CRC校验
- 🌡️ 温湿度传感器 (SHT30) — 滑动平均滤波、偏差计算、异常预警
- ⚖️ 称重传感器 (HX711) — 0-50kg 量程、±5g 精度
- 📏 超声波测距 (HC-SR04) — 包裹尺寸 L×W×H + 体积计算
- 🔥 红外测温 (MLX90614) — 表面温度监测，>60℃ 预警
- 📐 倾角传感器 (MPU6050) — 倾斜检测，>15° 预警
- 📳 振动传感器 (ADXL345) — 冲击检测，>3g 预警

### 下行控制（4类执行器）
- 🚪 门磁传感器 (MC-31) — 区域入侵检测
- 🔴 激光对射 (AB20-30) — 光束中断检测
- 🚨 声光报警器 (SG-01) — 自动/手动报警
- 🔌 继电器 (SRD-05VDC) — 远程设备控制

### 核心模块
- **通信仿真** — MQTT / Modbus RTU / RFID EPC Gen2 三协议仿真，CRC-16 校验，帧结构可视化
- **安防联动** — 4条联动规则，环境异常→报警+排风，区域入侵→报警+锁门
- **边缘计算** — 本地异常研判，正常数据定时上传，异常数据优先上报
- **室内定位** — UWB DW1000 节点，TDOA 算法，精度 ±10cm
- **全链路溯源** — 7步溯源链：入库→物理参数→姿态检测→室内定位→环境监测→边缘研判→云端同步
- **综合报表** — 14字段全维度汇总，CSV 导出
- **模拟数据录入** — 批量/自动/单条录入测试数据

## 技术栈
- 纯 HTML + CSS + JavaScript 单文件架构
- Canvas 原生图表（折线图、饼图、热力图）
- 移动端自适应（768px / 480px 双断点）
- 科技蓝配色 (#2563eb 系列)

## 使用
直接浏览器打开 `index.html` 即可运行，无需服务器或构建工具。
